# Pac-Man Lite: DSA Edition (ECE 2103 / 2104)

An interactive, educational arcade game demonstrating fundamental **Data Structures & Algorithms (DSA)** in real-time.

## Quick Start

### Option A: Standalone Executable (No Python Required)
Simply double-click:
```
PacmanLite.exe
```

### Option B: Run with Python
```bash
# 1. Run DSA verification tests
python test_dsa.py

# 2. Start the game
python main.py
```

## Features
- **Custom Data Structures**: Stack, Circular Queue, Min-Heap Priority Queue, Doubly Linked List, Graph Adjacency List, Binary Search Tree.
- **Pathfinding AI**:
  - **Pinky**: Breadth-First Search (BFS) using Circular Queue
  - **Blinky**: Depth-First Search (DFS) using Array Stack
  - **Inky**: A* Search using Min-Heap Priority Queue & Manhattan Heuristic
  - **Clyde**: Intersect Patrol & Scatter AI
- **Interactive Visualizer**: Press **`V`** to see real-time search frontiers, nodes expanded, and time complexity telemetry.
